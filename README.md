# 🛡️ EMCY – Test ton niveau digital

Quiz interactif de sensibilisation à la **cybersécurité** pour les jeunes, créé pour **EMC Youth** (association d'éducation numérique). À la fin du test, le participant obtient un niveau (**Cyber Smart**, **À risque** ou **Vulnérable**) avec des conseils personnalisés.

## ✨ Fonctionnalités
- Questionnaire interactif avec progression
- Calcul d'un score et attribution d'un niveau
- Conseils adaptés au résultat
- Interface au style « cyberpunk », 100 % front-end (aucun serveur requis)

## 📁 Structure
```
emcy-quiz/
├── index.html   # structure de la page
├── style.css    # thème visuel
└── script.js    # logique du quiz et des résultats
```

## 🚀 Lancer en local
Ouvrir `index.html` dans un navigateur.

## 🛠️ Stack
HTML5 · CSS3 · JavaScript
