Quiz web interactif qui permet aux jeunes d'évaluer leur **niveau de sensibilisation à la cybersécurité**, créé pour **EMCY — Cyberconfidence Space Youth**.

## ✨ Fonctionnalités

- **10 questions en situation** sur les risques numériques du quotidien : mots de passe robustes, phishing, vie privée sur les réseaux sociaux, cyberharcèlement, etc.
- **Retour immédiat** : chaque réponse est accompagnée d'une courte explication.
- **Score en direct** et profil final : *Cyber Smart*, *À risque* ou *Vulnérable*, avec des conseils pour progresser.
- **Partage du résultat** via l'API Web Share native.
- **Thème sombre / clair** et fond animé de style « cyberpunk ».
- **Aucune dépendance** : HTML, CSS et JavaScript purs.

## 📁 Structure

```
emcy-quiz/
├── index.html   # Pages : accueil, quiz, résultats
├── style.css    # Thèmes et animations
└── script.js    # Questions, calcul du score et résultats
```

## 🚀 Lancer en local

Aucune étape de build n'est nécessaire.

```bash
git clone https://github.com/ayakhama3/emcy-quiz.git
cd emcy-quiz

# Option 1 : ouvrir index.html dans le navigateur
# Option 2 : le servir en local
python -m http.server 8000     # puis ouvrir http://localhost:8000
```
